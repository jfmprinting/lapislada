# Frontend Design & Taste Rules

Proyek ini memberlakukan pedoman antarmuka **Taste Skill (Anti-Slop Frontend Guidelines)**. Aturan telah dipecah secara modular ke dalam folder `.agents/rules/`:

1. **[01_frontend_taste_core.md](file:///.agents/rules/01_frontend_taste_core.md)**:
   - Brief Inference (analisis konteks pengguna sebelum coding).
   - Core Configuration: The Three Dials (`DESIGN_VARIANCE`, `MOTION_INTENSITY`, `VISUAL_DENSITY`).
   - Brief → Design System Map & Default Stack Architecture.
   - Dial Definitions & Dark Mode Protocol.

2. **[02_frontend_taste_design.md](file:///.agents/rules/02_frontend_taste_design.md)**:
   - Typography (Sans over Serif default, scale discipline, descender clearance).
   - Color Calibration (single accent, no AI purple glow, WCAG AA contrast).
   - Layout Diversification & Anti-Center Bias.
   - Materiality, Shadows, Form patterns, dan Hero stack discipline.
   - Page Theme Lock & Performance / Accessibility Guardrails.

3. **[03_frontend_taste_motion.md](file:///.agents/rules/03_frontend_taste_motion.md)**:
   - Context-Aware Proactivity (Motion must be motivated).
   - Sticky-Stack, Horizontal-Pan, dan Scroll-Reveal Stagger Canonical Skeletons.
   - Larangan `window.addEventListener('scroll')` & forbidden animation traps.
   - Web approximation Apple Liquid Glass.

4. **[04_frontend_taste_tells.md](file:///.agents/rules/04_frontend_taste_tells.md)**:
   - AI Tells (pola terlarang seperti neon outer glow, 3 kartu fitur identik, Jane Doe data).
   - Larangan em-dash (`—`).
   - Reference Vocabulary pola UI modern (Bento, Kinetic Marquee, Spotlight Card, dll).

5. **[05_frontend_taste_workflow.md](file:///.agents/rules/05_frontend_taste_workflow.md)**:
   - Redesign Protocol (Preserve vs Overhaul, Audit before touching).
   - The Block Library contract.
   - Strict Pre-Flight Checklist sebelum menyelesaikan tugas UI.
   - Referensi kanonikal & perintah instalasi resmi.
